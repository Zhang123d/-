## 背景与切入点：单个文件正常，组合起来却可能有害

一个技能声称帮助排查云服务故障：说明文件要求准备诊断包，配置文件决定收集什么，脚本负责上传。分开看，读文件和发网络请求都可能正常；连起来才发现，敏感凭据被装进了上传内容。

论文用这个例子说明，Skill的风险分散在**提示、代码与配置**之间，而且取决于操作对象和上下文。规则扫描容易只看见孤立调用，直接让LLM判断又可能受正常用途包装或提示注入影响；动态检测则依赖能否触发行为。作者因此把问题改为：**先提取事实，再重建关联，最后判断它们是否构成恶意流程**。[§1–3，pp.2–4][background]

## 创新与实现：让规则和LLM围绕同一份证据工作

**第一步，找操作，暂不判恶意。** MalSkills用Semgrep解析代码与配置，提取执行、文件读写、网络通信等安全敏感操作（SSO）；LLM补充识别第三方封装和自然语言隐含的操作。原文要求模型提取的是“evidence facts, not verdicts”：输出操作类型、来源行号与匹配文本，而非直接给技能贴标签。[§4.1，pp.4–6][extract]

**第二步，追踪这些操作作用于什么。** 系统结合YASA指向与值流分析，追溯文件、命令、端点和载荷的来源；LLM辅助补全语义等价对象与不完整依赖。随后构建技能依赖图（SDG），连接**文件、操作、操作数和数据值**。关键不在于同时出现“读取”和“发送”，而在于读出的敏感数据是否进入了发送载荷。它不是完整的程序控制依赖图，LLM推断的关联也不能等同于实际执行记录。[§4.2，pp.6–7][graph]

**第三步，沿图判断完整行为。** 符号规则在相连的子图上匹配已知恶意模式，要求存在操作数依赖或值流关系；LLM再结合图证据与匹配结果，解释不完整、隐含或此前未覆盖的可疑流程。这样，模型面对的是有来源的操作与关联，而非只凭一份技能自述作判断。[§4.3，p.7][reason]

```mermaid
flowchart LR
    A[提示、脚本与配置] --> B[规则与LLM提取敏感操作]
    B --> C[追踪操作对象和数据流]
    C --> D[构建技能依赖图]
    D --> E[规则匹配与LLM上下文推理]
    E --> F[检测结论与证据]
```

作者还加入**神经到符号的反馈**：将LLM反复发现的稳定操作模式抽象为规则，经规范化、去重和留出语料验证后加入规则库；推理阶段则记录反复出现的可疑子图作为候选模式。这是规则复用机制，不是重新训练一个恶意技能检测大模型。[§4.1、§4.3，pp.5–7][extract]

## 实验设置与结论：有效性来自哪里，结果能推广多远

基准 **MalSkillsBench** 包含100条哈希去重后的已知恶意技能和100条热门良性技能，保留原始多文件结构。作者比较5种检测工具，默认使用 `gpt-5.3-codex-medium`；需LLM的基线也使用同一模型。实现包含2,665条Semgrep规则，覆盖10种语言；更深的YASA值流分析目前覆盖Python、JavaScript、Java和Go。[§5.1，pp.7–8][evaluation]

| 实验 | 论文结果 | 应如何理解 |
| --- | --- | --- |
| 200条基准检测 | 精确率0.95、召回率0.92、误报率0.05、F1为0.93 | 在所测工具中取得最佳F1；不代表没有漏报或误报 |
| 去掉符号提取器 | F1降至0.43 | 显式操作提取是该基准的重要支撑 |
| 去掉LLM推理器 | F1降至0.71，误报率升至0.49 | 上下文判断对区分正常功能与恶意行为很关键 |
| 7个注册站点的150,108条去重技能 | 告警620条，人工确认400条恶意 | 证明具备生态扫描价值；其余未告警样本不能据此认定安全 |

*来源：表3–4、§5.5，pp.8–10。去掉LLM提取器或符号推理器时，基准F1按表中精度仍为0.93；不能据完整系统得分推断每个组件都已被独立证明能提高准确率。*

野外告警的人工确认比例约为 **64.5%（400/620）**，明显低于平衡基准的精确率；真实生态仍需人工复核。400条确认样本中89.8%归为数据盗取或外传。未告警区域没有完整标签，因此不能据此计算整体召回率或真实恶意率。[表6、§5.5–6，p.10][wild]

这篇论文的推进，是把检测单位从孤立文件和危险关键词，转向**跨文件、围绕具体数据对象的行为证据链**。对后续阅读最有价值的检验标准也由此明确：证据从哪里来、关联如何建立、正常用途如何排除，以及基准成绩能否在真实生态中保持。更隐含的文档诱导、LLM遭对抗干扰及有限的深层语言覆盖，仍是作者承认的边界。[§6，p.10][wild]
